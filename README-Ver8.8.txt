チャス競馬研究所 Ver.8.8 統合更新
============================

今回のファイルは、実際に稼働している Ver.8.7 の chass-latest.js を基準に作成した「置換用」Ver.8.8です。

【Ver.8.7から維持】
- NAR現在オッズ取得後の即時同期
- CHASS FINALへの市場反映
- NAR結果取得 → 1〜3着反映 → 保存 → ダッシュボード再集計
- 予想フローの「頭数 / 市場 / 結果 / 保存」状態表示

【Ver.8.8で追加】
- ◎○▲ TOP3捕捉率
- ◎ / ○ / ▲ / △ / ☆ の印別勝率・複勝率
- 💎穴馬の複勝率・平均人気・平均単勝
- ⚠️人気馬の圏外率
- AI勝率 / AI複勝率の予測誤差集計
- 予想TIMEと実走TIMEの平均絶対誤差
- 勝率モデル / 総合モデル / 期待値モデル / CHASS FINAL のモデル別成績
- actualTimes / modelSnapshot 等を保存済みレースへ同期する項目を追加

【導入方法】
1. GitHub の chass-latest.js を、このフォルダの chass-latest.js で置き換える
2. index.html が既に app.js → chass-latest.js の順で読んでいれば変更不要
3. Commit → Cloudflare デプロイ完了後、Safariを再読み込み
4. 画面上部が Ver.8.8 になれば反映完了

【動作確認】
- 現在オッズ取得後：市場頭数が表示される
- レース結果取得後：着順が入り、保存後に検証ダッシュボードが1R以上になる
- 検証ダッシュボード下部に「検証精度・フィードバック」が追加される
- レース数が少ない間は比率が大きく動くため、50R / 100R以上で傾向判断する

注意：
この更新は chass-latest.js のみを置き換える方式です。app.js / worker.js / index.html を今回の更新だけのために変更する必要はありません。
