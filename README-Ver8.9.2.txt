CHASS KEIBA LAB Ver.8.9.2 更新内容

導入
- GitHub の chass-latest.js を同名ファイルで置き換えるだけです。
- index.html / app.js / worker.js は今回変更不要です。

主な改善
1. QUICK VIEWをiPhone向け2x2指標表示に固定
   - AI勝率 / 複勝率 / TIME / 期待回収率
   - 実オッズ / 実人気を別行表示
   - 「勝12.0%複」「TIME 1:18総合」の文字詰まりを解消

2. 各馬詳細へ市場情報を同期
   - 保存済みNAR実オッズ・人気を各馬カードのサブ情報へ反映
   - 1人気/1倍など取込時の初期値が残る問題を表示側で補正

3. TOP3指標の定義を修正
   - ◎○▲ 1頭以上捕捉率
   - ◎○▲ 3頭完全捕捉率（着順不問）
   - 1Rあたり平均捕捉頭数
   を分離。単一のTOP3捕捉率による誤解を防止。

4. 確率検証を改善
   - AI勝率 MAE + Brier Score
   - AI複勝率 MAE + Brier Score
   - Brier Scoreは小さいほど確率予測が良好

5. 実走TIME保存を強化
   - /api/nar/sync の actualTimes を自動捕捉して保存
   - 結果済みなのに実走TIMEが未保存の場合、一度だけNAR同期を試行
   - 取得できたデータから予想TIME平均絶対誤差を集計

6. 検証画面を整理
   - Ver.8.8旧追加検証パネルを非表示にし、Ver.8.9.2統合パネルに一本化
   - 全期間 / 最新50R / 最新100R
   - モデル別 / 印別 / 穴馬 / 危険馬 / 較正 / TIME誤差を同一パネルに表示

注意
- 1Rなど少数母数のMAE/Brier/複勝率は大きく振れます。50R・100R以上の累積を主判断にしてください。
- NAR側ページに実走TIMEが掲載されていて、現在のworker.jsがactualTimesを返せる場合にTIME誤差が集計されます。
