CHASS KEIBA LAB Ver.7.9 改善パック

【今回の修正】
1. レース後検証を独立カード化
   ・「運用・レース後検証」の折りたたみ内からレース結果部分を外へ移動します。
   ・運用パネルを閉じても、レース後検証は常時表示されます。

2. NAR公式取込みを復活
   ・「NAR公式から結果・最終オッズを取得」ボタンを常時表示します。
   ・同一Workerの /api/nar/sync を利用するため、Worker URLの手入力は不要です。
   ・船橋 / 笠松 / 園田 / 姫路 / 門別に対応します。

3. 公式取得時の自動反映
   ・1着 / 2着 / 3着
   ・各馬の実走タイム（取得できた場合）
   ・最終単勝オッズ / 人気
   を画面へ反映します。
   その後、保存済み予想を更新し、検証ダッシュボードを再集計します。

4. 手入力も残します
   ・公式取得できない場合は従来どおり1〜3着馬番を手入力できます。
   ・入力時の自動保存・検証も維持します。

5. Ver.7.8のUI改善を維持
   ・各馬詳細のコンパクト化
   ・QUICK VIEW
   ・CHASS FINAL
   ・市場取得時だけMARKET CHECK表示
   をそのまま残しています。

【更新方法】
現在 chass-loader.js 方式なら、GitHubの chass-latest.js をこのZIP内の chass-latest.js に置き換えるだけです。
index.htmlへのscript追加・編集は不要です。

【確認ポイント】
・ヘッダーが Ver.7.9
・「レース後検証」が「運用」パネルとは別の独立カードになっている
・レース後検証に「NAR公式から結果・最終オッズを取得」ボタンが表示される
・ボタン取得後に1〜3着、オッズ、実走タイムが反映される

【前提】
worker.js 側に /api/nar/sync が存在することが必要です。
既存Ver.7.3 Worker APIはこの条件を満たしています。
