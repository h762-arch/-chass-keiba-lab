チャス競馬研究所 Ver.7.5 パッチ

【追加内容】
1. CHASS FINAL
   - ◎ / ○ / ▲ を最終判断としてレース情報直下に表示
   - 勝率・複勝率・総合評価・期待値・AIフェアオッズを統合
   - 💎穴馬 / 💎💎💎激推し大穴 / ⚠️人気馬注意 を最上部で確認

2. 期待値評価の強化
   - 実オッズ取得後は AI勝率 × 実オッズ で期待回収率を表示
   - 市場未取得時はAIフェアオッズを表示
   - 市場データがない場合は無理に穴判定しない

3. モデル分離
   保存時に以下を別々に記録します。
   - 勝率モデル1位
   - 総合評価モデル1位
   - 期待値モデル1位
   - CHASS FINAL 1位

4. 検証ダッシュボード追加
   - 💎穴馬の指名数 / 勝率 / 複勝率
   - 💎穴馬の平均人気
   - 単勝回収率（保存済み単勝オッズから概算）
   - ⚠️人気馬の圏外率
   - 4モデルの勝率 / 複勝率比較

【導入方法】
GitHubリポジトリのルートに
  chass-v7.5-patch.js
をアップロードしてください。

index.html の最後を

  <script src="app.js"></script>
  <script src="/chass-v7.4-patch.js"></script>
  <script src="/chass-v7.5-patch.js"></script>
  </body>
  </html>

に変更してCommitします。

Cloudflareのデプロイが成功したらSafariで再読込してください。
画面上部が Ver.7.5 になれば導入成功です。

【注意】
Ver.7.5はVer.7.4の後読み拡張です。
app.js / worker.js / wrangler.jsonc は今回変更不要です。
