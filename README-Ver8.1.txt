チャス競馬研究所 Ver.8.1

Ver.8.0 COMPLETE をベースに現在オッズ自動取得を統合。

追加機能
- 予想画面に「現在オッズ」独立カード
- NAR公式の単勝オッズ取得専用 /api/nar/odds
- 取得オッズから人気順位を自動生成
- AI勝率 × 現在オッズで期待回収率を再計算
- 💎穴馬 / ⚠️人気馬注意 / CHASS FINALを再判定
- 60秒ごとの自動更新 ON/OFF
- レースごとのオッズ履歴をlocalStorageへ保存（最大120スナップショット）
- 従来のレース後検証、結果・最終オッズ取得、検証ダッシュボードは維持

注意
- 現在オッズ取得対応競馬場は既存Ver.8.0と同じ：船橋・笠松・園田・姫路・門別
- 発売前やNAR側未掲載時は架空値で補完せず取得不可と表示
- Cloudflare WorkersへはこのZIP内の index.html / app.js / styles.css / worker.js をセットで反映してください。
