CHASS KEIBA LAB Ver.8.9 更新セット

【導入】
1. GitHub上の chass-latest.js を、このフォルダの chass-latest.js で置き換える
2. Commit / Push
3. Cloudflare Workers のデプロイ完了を待つ
4. iPhone Safariで再読み込み
5. 画面上部が Ver.8.9 になれば反映完了

index.html / app.js / worker.js の変更は不要です。

【Ver.8.9 主な改善】
・予想 → 市場 → CHASS FINAL → 結果 → 検証をレース単位の統一スナップショットとして保存
・勝率モデル / 総合モデル / 期待値モデル / CHASS FINAL の1位を保存
・検証ダッシュボードの「対象0」になりにくいフォールバック集計を追加
・全馬比較をiPhone向け2段カードレイアウトへ再構成
・CHASS FINALに「選定理由」を追加
・現在オッズ取得後の市場表示同期を強化
・検証期間を「全期間 / 最新50R / 最新100R」で比較可能
・既存の結果、オッズ、予想情報、localStorage保存を維持

【重要】
Ver.8.9は予想モデルの重みを少数レースだけで自動変更しません。
まず予想・市場・結果・誤差を正しく蓄積し、50R / 100Rの母数で改善判断できる基盤を作る更新です。

【確認してほしい項目】
・NAR現在オッズ取得後、市場表示が8/8頭などで統一される
・CHASS FINALに選定理由が表示される
・全馬比較で文字が重ならない
・結果保存後、検証ダッシュボードのモデル別「対象」が増える
・最新50R / 最新100Rボタンが表示される

問題が出た場合は chass-latest-Ver8.8-backup.js が更新前バックアップです。
