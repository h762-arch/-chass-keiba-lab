チャス競馬研究所 Ver.8.2 改善パック

【今回の目的】
・能力評価と市場期待値を分離
・実オッズ未取得時に人気/期待値を確定表示しない
・TIMEを「ハマり / 標準 / 不利」の3シナリオで表示
・現在オッズの取得時刻と前回比を保存・表示
・データ整合性を通常時は1行に圧縮
・最終判断と全馬比較をスマホ向けに整理
・既存のレース後検証、検証ダッシュボードを壊さない

【入れ替えるファイル】
chass-latest.js だけです。

すでに index.html が以下の1行だけで最新版を読む構成なら、index.html は変更不要です。
<script src="/chass-latest.js"></script>

【重要】
Ver.8.2は、オッズ種別が「実オッズ」と確認できた場合だけ
・実オッズ
・人気
・期待回収率
・💎穴馬
・⚠️人気馬注意
を確定表示します。

予想オッズ/種別不明/未取得の場合は、市場評価は「保留」にします。
これは誤った期待値表示を防ぐための仕様です。

【TIME 3シナリオ】
既存の予想TIMEを標準として、ブレ幅・位置取り失敗率から
・ハマり
・標準
・不利
の推定値を表示します。
推定値なので実測値とは区別してください。

【導入】
1. GitHubの既存 chass-latest.js をこのファイルで置き換える
2. Commit changes
3. Cloudflare Pages/Workers の自動デプロイ完了を待つ
4. Safariで再読み込み
5. 画面上部が Ver.8.2 になっていることを確認

【確認項目】
・レース後検証が独立表示される
・検証ダッシュボードが開く
・実オッズ未取得では期待回収率が出ない
・現在オッズ取得後に期待回収率が出る
・最終判断に「能力」「信頼度」「市場期待値」が分離表示される
・全馬比較がコンパクト表示になる

【補足】
既存 app.js / worker.js / styles.css はこの改善パックでは変更しません。
現在オッズ取得関数は既存の fetchCurrentNarOdds または fetchOfficialNar を利用します。
