チャス競馬研究所 Ver.8.7 更新
============================

目的
- NAR現在オッズ取得後にCHASS FINALと保存データへ即時同期
- NAR結果取得後に保存済みレースへ結果を反映し、ダッシュボードを自動再集計
- Ver.8.6で発生していた「現在オッズ8頭反映なのにCHASS FINALがオッズ未取得」
  「結果取得済みなのにダッシュボード0R」を補正

導入
1. GitHub上の chass-latest.js を、この更新版で置き換える
2. index.htmlが既に chass-latest.js を読み込む構成なら追加編集不要
3. デプロイ後、Safariを再読み込み

確認
- 現在オッズ取得 → CHASS FINAL「市場反映済 8頭」
- 結果取得 → 1〜3着自動入力 → 保存 → ダッシュボード再集計
- 予想フローに「頭数 / 市場 / 結果 / 保存」の状態表示が出る
