CHASS KEIBA LAB Ver.7.8 改善パック

【改善内容】
1. 各馬詳細をさらに圧縮
   ・通常表示は 馬番 / 印 / 馬名 / 勝率 / 複勝率 / TIME / 総合 を中心に維持
   ・＋材料 / −材料 / 不明 は「詳細分析を見る」の中へ移動
   ・分析データ自体は削除しません

2. 全馬比較を実用的な比較表へ改善
   ・馬番 / 印 / 馬名に加えて、AI勝率 / 複勝率 / TIME / 総合を表示
   ・iPhoneでは横スクロール表ではなく、コンパクトカード表示

3. CHASS FINALを明確化
   ・上位3頭へ FINAL 1位 / 2位 / 3位 を表示
   ・「勝率順位」と「最終判断順位」が違う場合でも理由が分かるよう説明を追加
   ・FINALは勝率、総合評価、複勝率、信頼度、市場取得時の期待値を統合

4. Ver.7.7の改善を維持
   ・市場未取得時はMARKET CHECKを非表示
   ・市場取得時は必要候補中心
   ・既存6,000回シミュレーション、自動取込、保存、検証ロジックは変更しない

【更新方法】
すでに chass-loader.js 方式へ変更済みなら、
GitHub上の chass-latest.js を今回のファイルへ差し替えるだけです。
index.htmlへのscript追加は不要です。

【確認ポイント】
・ヘッダーが Ver.7.8
・各馬カードから＋材料/−材料/不明が消え、「詳細分析を見る」の中にある
・全馬比較で 勝 / 複 / TIME / 総合 が一画面で確認できる
・CHASS FINALに FINAL 1位〜3位 が表示される
